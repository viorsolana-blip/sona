2. Description of Service

Sona implements a marketplace for verified Raydium CPMM Fee Keys on Solana. Wallet authentication, chain-verified inventory, persistent listings and bilateral atomic settlement are implemented. Each sale requires the seller’s approval and the buyer’s signature. Listings are coordinated by the marketplace server; there is no custom Sona program or standing escrow. This build runs locally; a public deployment and independent security audit have not been completed. The current scope includes:

  • Discovering verified Raydium CPMM Burn & Earn Fee Keys held by a connected wallet.
